# محاسب سيدي سالم – Sidi Salem Accountant
صاحب المشروع: شراحي محمد البشير

## MVP v1
نسخة Web/PWA أولية قابلة للتشغيل محلياً، تستخدم IndexedDB كقاعدة بيانات حقيقية داخل المتصفح، وليست بيانات وهمية.

### التشغيل
1. ثبّت Node.js 20+.
2. افتح مجلد المشروع.
3. `npm install`
4. `npm run dev`
5. افتح الرابط الذي يظهر في الطرفية.

### الإنتاج
`npm run build` ثم `npm run preview`.

### ملاحظات هندسية
- البيانات محفوظة في IndexedDB على الجهاز/المتصفح.
- كل عملية لها ID مستقل.
- المبالغ المتبقية في الديون والمشتريات = الأصل - المدفوع.
- هذه النسخة لا تعتبر نظام محاسبة قانوني أو بديلاً عن محاسب معتمد.
- المرحلة التالية المقترحة: Backend PostgreSQL + API + حسابات مستخدمين + مزامنة سحابية + PDF حقيقي + سجل دفعات مرتبط بالدين + تقارير شهرية + تصدير/استيراد.
